## Issue Triage Guidelines

### Priority Levels
- **P0 (Critical)**: System down, data loss, security issue
- **P1 (High)**: Major feature broken, significant UX issue
- **P2 (Medium)**: Minor features affected, workaround exists
- **P3 (Low)**: Nice to have, cosmetic issues

### Labels
- `bug` - Bug report
- `feature` - Feature request
- `enhancement` - Enhancement to existing feature
- `documentation` - Documentation update
- `question` - Question/discussion
- `good-first-issue` - Good for new contributors
- `help-wanted` - Help needed
